# Sistema visual

Identidad editorial para una carpintería, inspirada en principios de composición de Ashton Bespoke sin reproducir su marca, logotipo, textos ni identidad comercial.

## Colores

```css
:root {
  --color-burnt-wine: #38141b;
  --color-ink-stone: #262626;
  --color-warm-parchment: #e0ded8;
  --color-white: #ffffff;
}
```

El pergamino cálido domina fondos y superficies; la tinta define texto, navegación, bordes y líneas; el vino se reserva principalmente para el pie de página y secciones oscuras puntuales; el blanco sirve para contraste y texto sobre fondos oscuros. No se incorporan colores saturados ni degradados.

## Tipografía

- Titulares: Cormorant Garamond, con Georgia como alternativa disponible.
- Navegación, etiquetas y controles: Inter, con una sans-serif del sistema como alternativa.
- Texto corriente: Arial o sans-serif legible.
- Escala de referencia: controles 15–16 px, subtítulos 18 px, títulos 32 px, destacados 46 px y título principal hasta 60 px.
- Titulares con interlineado cercano a 1.10; párrafos alrededor de 1.40. Ajusta tamaños en móvil y evita desbordamientos.

Las fuentes comerciales de referencia no se copian. Las alternativas web pueden utilizarse cuando su licencia y disponibilidad estén verificadas.

## Composición y componentes

- Fotografía horizontal protagonista, encabezados serif y espacio negativo generoso.
- Ritmo vertical amplio, líneas de 1 px y marcos finos.
- Imágenes rectangulares sin esquinas redondeadas; tarjetas sin sombras.
- Controles con esquinas de hasta 4 px; enlaces subrayados cuando corresponda.
- Navegación sobre el hero solo si el contraste se mantiene.
- Pie de página vino oscuro y texto blanco.
- Componentes previstos: hero, presentación editorial, secciones en dos columnas, galerías, navegación por categorías y pie de página.
- El catálogo usa tarjetas limpias con un marco provisional rotulado cuando falte una fotografía real. Los formularios de medidas y la solicitud de cotización conservan los mismos bordes, tipografía y colores, con estados de error legibles.

El panel administrativo comparte tipografía, colores y bordes, pero privilegia tablas, formularios, filtros y estados claros. La estética no debe dificultar encontrar un trabajo ni gestionar contenido.

## Accesibilidad y comportamiento

Mantén contraste suficiente, navegación por teclado, estados de foco visibles, etiquetas de formulario y mensajes comprensibles. Respeta el ancho móvil, usa imágenes optimizadas con carga diferida cuando aplique y evita animaciones que perjudiquen el rendimiento. No inventes un monograma ni datos del negocio.
